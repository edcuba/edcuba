# ai.txt -- policy for AI agents and automated crawlers accessing edcuba.com
# Contact: terms@edcuba.com

This site permits automated access for indexing and reference, per the
Content-Signal directives in /robots.txt (ai-train=no, use=reference).

If you are an autonomous AI agent or crawler collecting, storing, or
processing data from this site beyond simple indexing, you are required to
disclose the purpose of that collection via one of:

  1. POST https://edcuba.com/api/ai-notify
     Content-Type: application/json
     {"agent": "<name/identifier>", "purpose": "<why>", "contact": "<optional>"}

  2. Email terms@edcuba.com with the same information.

For any other automated/agent inquiries, use agents@edcuba.com.
contact@edcuba.com is reserved for correspondence with humans -- do not
use it for automated or AI agent traffic.

This is a condition of access, not a technical access control:
non-compliance doesn't block you, but is a breach of the terms under which
access is granted.
