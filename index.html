Experience

Research Assistant, Interactive Data Analytics Group, University of Zürich (April 2023 – June 2024). Led a project in AI for Sustainability Research. Built LLM infrastructure and data processing pipelines using LlamaIndex, FastAPI, and Qdrant to power a Vue.js application.

Technical Student, Machine Learning for HPC, CERN (February 2022 – March 2023). Benchmarked HPC GPU hardware for Machine Learning in High-Energy Physics. Developed ML pipelines using Graph Neural Networks for particle shower reconstruction using PyTorch and C++.

Full-Stack Engineer, Procivis AG (July 2018 – September 2019). Developed mobile and web applications from scratch to production using React Native, React, Python, C++, and Kubernetes.
